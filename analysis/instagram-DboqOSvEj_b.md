## What's reusable
**Steal:**
- Open on the command itself with zero setup — the premise doubles as the hook
- Show a real, unscripted complication (request denied) instead of a clean happy-path demo; the friction is what sells the "this is really autonomous" claim
- A persistent live-status UI overlay (call state + transcription) makes an otherwise invisible AI process visible for the full runtime, which is what a phone-call demo needs to not feel like a screenshot of a chat log

**Don't steal:**
- The custom branded J.A.R.V.I.S. dashboard — needs real product/UI build work to look this credible
- A voice-agent stack good enough to run an unscripted live phone call convincingly — this depends on the underlying model/voice pipeline, not on editing choices

**Effort to replicate:** high
