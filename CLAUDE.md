## What this repository is

This is not a software project — there is no build system, package manager, test suite,
or source code here. It holds a single self-analysis archive generated on 2026-07-08:

- `evidence.md` — raw observations about account/session/repo activity, with explicit
  confidence levels and receipts for every claim.
- `mirror.md` — a reflective summary written from that evidence.
- `roadmap.md` — a 30-day plan (waste/delegate/focus/drop/keep/rhythm) derived from the evidence.

Do not invent build/lint/test commands for this repo; none exist.

  we ship since the last setup task?" If the answer is nothing, say so and offer the
  smallest shippable action first instead of proceeding straight to more setup/research.
- Do not create repos or files named test/tmp/scratch in this account; use the session
  scratchpad instead.

  digging — point one-off niche research requests toward setting up or using that
