## What's reusable
**Steal:**
- Name the exact command or UI action in the first ten seconds (`/analyze`), not the benefit. A literal string the viewer can type is more persuasive than any adjective.
- Show the tool working before naming the product. The demo runs 0:03–0:37; the product is named at 0:38, once the capability is already believed.
- Escalate scope at the midpoint: one video, then dozens at once. The second, larger claim lands only because the first was demonstrated.
- Enumerate the output fields aloud — "transcript, format, topic, angle, storytelling structure, hook analysis, visual layout". A list of concrete deliverables does work that a vague "full breakdown" cannot.
- Split layout keeps a face on screen while the screen recording carries the information — retains talking-head connection without giving up demo space.

**Don't steal:**
- The 13K→20.1K follower overlay: unverifiable, undated, and only persuasive from an account whose numbers the viewer can check.
- "Changed social media forever" framing, which depends on the tool being genuinely new at time of posting and ages badly.
- Deferring the paid dependency to 0:38. It converts, but it is why alignment scores 3 rather than 5, and it costs trust on rewatch.

**Effort to replicate:** medium
