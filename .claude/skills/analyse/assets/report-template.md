# Per-video report template

Follow this structure. The order is deliberate: hook first because it is what the
user came for, replication last because it is the answer to "so what".

Keep quotes verbatim — the credibility of every judgement below rests on the reader
being able to check it against the words on screen.

---

## Notes

**Header line.** Every comparable number lives there so a reader scanning ten
reports can compare without opening them. Do not drop fields — write
`engagement data not exposed by the platform tool` rather than omitting the slot,
so a missing number is visibly missing rather than ambiguous.

**Watched span.** On a clipped YouTube watch, add
`Visual analysis covers 0–30s only.` under the header. A reader must be able to
tell a thin analysis from a thin video.

**Unavailable video.** Do not produce a full report. Write the header, then
`**Unavailable:** <reason>`, and nothing else. An empty template full of "unclear"
looks like analysis and is not.
