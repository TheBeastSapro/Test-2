Connectors

A connector hands the agent another service's tools. Connect NexLev and it can query the niche finder and pull outliers itself, in the same conversation, instead of asking you to paste numbers.

This is not the same as a provider key below. A provider key lets the pipeline call a vendor; a connector lets the agent call one. They fail separately, so they are configured separately.
