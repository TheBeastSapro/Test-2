          pipeline call a vendor; a connector lets the agent call

          Mirrors your work into a private GitHub repository so it
          survives this machine. Scripts, briefs, shot lists, captions, learned styles
          and channel memory go. Renders do not — GitHub refuses files
          over 100 MB and git keeps every version for ever, so a repository
          collecting finished videos becomes unpushable within weeks and cannot be
          shrunk again without breaking every other machine's copy. The video is made
          again from the work; the work is the part that took thinking.
        


        

          
          
          
        


        {# The device flow: GitHub shows a box, you type the code. Chosen over a web
           redirect on one decisive fact — the token exchange sends no client secret, so
           a zip can carry the client ID safely. A redirect flow would need a secret in
           the archive, which hands every operator the key to every other operator's app. #}
