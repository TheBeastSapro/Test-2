Styles

An editing style is a whole edit kept as data — cut rhythm, transitions, grade, caption discipline, motion. Learn one from a creator's videos, then apply it, mix it with another, or improve on it.

Learn one from a creator

Several videos by the same creator rather than one — a single video is an anecdote, and a style is what survives across their work. Each is measured on its own, so one file that cannot be read costs one reference instead of the attempt.
