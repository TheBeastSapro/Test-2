# Video / Edit QC Workflow (run when owner pastes a video link or file: "QC, watch this")

When the owner pastes an edited video (YouTube/unlisted link, Drive link, or uploaded file) and asks to QC it ("watch this", "QC this edit"), run this exact pass against the editing brief, the script the edit was built from, and the creature's editor-materials sheet. This is the video/edit counterpart to `claude/script-qc-workflow.md`. Return correction notes as forwardable DMs (numbered, with timestamps, no em dashes).

Reference docs: `claude/editor-brief-2026-07.md` (the style standard the edit is graded against), `claude/editor-evaluation-2026-07.md` (benchmarks + standing editor-brief items + the "dark ≠ illegible" lesson), the per-video editor-materials sheet (canon key images + fan-art traps; e.g. `claude/editor-materials-trevor-cannot-survive.md`), and the script/QC-notes doc for that video (so on-screen must match VO line by line).

## ACCOUNTABILITY — standing rule (owner-requested 2026-07-24)
The owner will NOT remember every check. It is Claude's job to run the ENTIRE pass proactively on every edit QC and REPORT a checklist status at the end (green / fix-sent / open), without waiting to be asked. Specifically:
- **Find the SMALL details, not just the big ones.** Editor mistakes hide in one misspelled keyword pop, one wrong date, one frame of the wrong creature, a jaw that contradicts the VO, an SFX a beat late, a title card that changed font between sections. Go looking for these on purpose.
- **Check canon on EVERY on-screen image**, against the editor-materials sheet and the narration line. The image must never contradict the VO (jawless means jawless on screen).
- **Verify every image/asset for DRIFT** (wrong creature, wrong series, fan-art trap, anachronism, style/font/canvas drift, reused-too-long, repaint that lost canon anatomy). Use the asset-drift sub-checklist below — do not eyeball-and-move-on.
- **If a check can't be completed** (can't read a frame, can't confirm a source image, VO pronunciation ambiguous), say so and list it as an OPEN item the owner must close before publish — never pass it silently.
- **End every QC with the full checklist** so the owner sees nothing was dropped.

## Inputs
- **The video** (link or file) — always.
- **The script / QC-notes doc** it was edited from — pull it so on-screen text, keyword pops, and image claims can be checked line-by-line against the VO.
- **The editor-materials sheet** for that video's creatures (approved canon images + flagged fan-art traps). If none exists, canon is checked against the creature's wiki gallery / creator accounts and flagged as best-effort.
- **Which editor** produced it (Vu = cinematic composites, per-section checkpoints; Abel = Ficknime-native kit) — tailor the notes and known-watch-items to that editor. If unknown, check the Drive file owner's email.

## How to actually watch and measure (don't just vibe it)
- **YouTube / unlisted link:** `mcp__NexLev__watch_youtube_video_and_ask` to watch and ask targeted questions (canon, text, gags, sync). Also pull the transcript for VO check.
- **Drive link / uploaded file:** download, then use `ffmpeg` in the cloud container.
  - **Drive download that actually works (confirmed 2026-08-03).** A large Drive file returns a virus-scan interstitial, not the file. Fetch `https://drive.google.com/uc?export=download&id=FILE_ID` with a cookie jar, parse the form for the `uuid` and `confirm` values, then GET `https://drive.usercontent.google.com/download?id=FILE_ID&export=download&confirm=t&uuid=UUID` with the same cookie jar. A plain `curl -L` on the first URL silently writes a 2 KB HTML file. Avoid the base64 MCP download for large files, it floods context.
  - **Shell cwd resets between Bash calls** — use absolute paths or re-`cd` in every command.
  - **Always pass `-nostdin -loglevel error` to ffmpeg.** Default ffmpeg progress output floods the context with hundreds of `frame= ... speed=` lines.
  - **Motion / dead-zone measurement:** extract frames at 2 fps, compute the percentage of pixels changing by more than ~12/255 between consecutive frames. Report the average change per 0.5s and flag any stretch ≥4s where EVERY sample stays under ~4%. Do not merge adjacent low runs across a high-motion blip; that inflates the dead-zone count badly (it reported a false 13s hold in the 2026-08-03 pass before being tightened). Benchmarks so far: Vu first half 22%/s, Abel Trevor full 12.1%, Vu Analog Horror full **25.1%**.
  - **Audio:** `ffmpeg volumedetect` for mean + max, `loudnorm=print_format=json` for integrated LUFS, true peak and LRA. Target -14 to -16 LUFS, true peak below -1 dBTP, no clipping. **Check LRA specifically:** under ~2 LU means an over-limited flat mix where the bed never ducks and SFX cannot punch. Also confirm zero full-scale samples separately, since a mix can be over 0 dBTP intersample while having no hard-clipped samples.
  - **Specs:** resolution (≥1920x1080), fps (30), codec (H.264 MP4), bitrate. **Check bitrate, not just resolution** — a 1080p60 file at <1 Mbps will block up in dark scenes even though the resolution passes.
  - **Canon / text / spelling:** extract key frames at each image change and READ them (Read tool on the frame PNGs) to verify creature anatomy, on-screen keyword spelling, dates, and title cards. **Contact sheets first, full-res second.** Build 4x5 contact sheets at 1 frame per 5s (about 7 sheets for a 10 minute video) and Read those to triage, then pull full-resolution frames only for the suspects. Low-res contact sheets DO produce false positives (a Monument Mythos hand-drawn US map read as "Chinese dragon scroll art" at thumbnail size, and "CIVIL" read as "CIUIL") — never report a text or canon finding from a contact sheet alone.
  - **TEXT INVENTORY — always run OCR (learned 2026-07-27).** Scene-change frames MISS keyword pops, because pops animate in between cuts. Run `tesseract --psm 11` over a 1 fps frame extraction to get a complete on-screen text inventory with timestamps, then filter out the persistent title. This is how you catch missing dates, typos, palette-colored text, and full-sentence subtitles. A frame-only sweep will falsely report "zero keyword pops". **Wait for the OCR job to finish before analysing** (check for a sentinel file) — reading a partial `ocr_raw.txt` silently truncates the inventory and will make a whole section look textless.
  - **Red-text sweep (added 2026-08-03).** Tesseract misses coloured pops on busy backgrounds. Mask for saturated red pixels per frame as a second pass to catch pops OCR dropped. Expect false positives from red imagery (the Iris planet lit the whole finale up), so confirm each hit by reading the frame.
  - **VO:** `faster-whisper` (base.en) on the extracted audio. Whisper drops chunks on a dense music bed — before reporting a VO gap, confirm it with an RMS-per-0.5s analysis. Flat RMS through the "gap" means the transcript dropped it, not the VO. Whisper also **hallucinates repeated lines** on a heavy bed (the 2026-08-03 pass produced "ever seen the whole thing" five times and "One reality" four times). Re-transcribe any suspect window with `small.en` and `condition_on_previous_text=False` before drawing any conclusion, especially before claiming a CTA is missing.

## The pass, in order
1. **Motion (the #1 rule):** no shot fully static; Ken Burns on every held image; icons/text always animate in. Flag every static hold and every stretch >4s with no change (give timestamps).
2. **Pacing / dead zones:** something changes every 2–4s; never >8s on one asset. Cross-reference the script's editability flags — the imageless verdict/closer beats especially (editor should hold on a creature beauty shot / title card, not dead air).
3. **Canvas & layout:** white canvas (unless a deliberate cinematic push-in); images boxed/centered, not stretched (except intentional reveals); persistent creature-name title top-center every section; consistent bold font. Flag any section where canvas/font/title style DRIFTS from the others. **Check title CASE and the article ("The") on every section title** — a lowercase title can run for a whole section unnoticed. Also check text stays INSIDE its boxed image and does not spill onto the white canvas.
4. **Keyword pops:** 2–4 per section, synced to VO punch words/dates/locations; **no full-sentence subtitles** (check for these explicitly, they are easy to miss and directly against brief). Check every pop for spelling, hyphenation, correct date, correct name, consistent numeral formatting (40ft vs 20 ft), consistent capitalisation, and that it matches the VO word it lands on. **Count pops PER SECTION and check the count holds through the finale** — density that tapers in the last two sections is a retention problem and is easy to miss when the early sections are dense. **Also check pop QUALITY:** a section can technically hit 2 pops and still fail if both are filler connectives ("At that point", "mistake") rather than dates, names or canon numbers. **And discount text that is baked into a source image** (a logo, a title card in the asset) — that is not an editor-added pop.
5. **CANON image accuracy (hard):** every creature image from the materials sheet's approved set (wiki gallery / creator accounts), never a flagged fan-art trap. On-screen anatomy must match the VO line exactly (the Long Horse "no lower jaw" case: VO says jawless, skull on screen must be jawless; the Horned Serpent case: VO says "no one has ever seen the whole thing", so the whole body must not be on screen). Flag every contradiction with timestamp + what the VO says vs what's shown.
6. **ASSET DRIFT (run the sub-checklist below):** wrong creature, wrong series, anachronism, style drift, reuse-too-long, repaint-lost-canon. This is where the owner most wants small catches.
7. **Tone / grade — USE THE CORRECTED RULE (learned 2026-07):** distinguish two cases. (a) Non-canon bright scenes (arbitrary cartoon/clip-art daytime an editor chose) → should be darkened/desaturated to match dread. (b) Canon-daylight creatures (Siren Head and any creature whose Henderson/creator source images are genuinely daytime) → KEEP the daylight; it's canon-faithful. Only pull saturation if it reads comedically bright; never force to night. Owner's canon knowledge overrides a blanket "make it dark" instinct. Also: night scenes need 2–3 bright anchors (lit car, lamp pools, rim light, white-on-dark figures) — dark, not invisible/illegible. Measure mean luminance per frame; anything under ~30/255 is a legibility flag, but check the p95 highlight in the same frames before calling it — a mean of 16 with p95 of 101 has anchors and is fine.
8. **SFX:** synced to visual cues (whoosh on pops, boom on reveals, glitch/glass where earned) over a dark ambient bed. "A cut without a sound is a wasted cut." Flag pops/reveals with no SFX and any SFX off-sync from its cue. Measure it: detect hard visual cuts (frame delta >60%) and audio transients, and report the percentage of cuts with a transient within 0.6s. Caveat this number when LRA is very low, since a squashed master flattens transients and depresses the score regardless of whether SFX were placed.
9. **Audio levels:** mean -14 to -16 dB, peaks < -1 dB, no clipping, music ducked under VO.
10. **Humor gags:** each script dry-joke line gets a timed visual gag (badge, meme, emoji-icon). Flag joke lines with no gag or a gag landing off the line. **A gag must stay in register** — a real-celebrity late-night meme clip, a licensed cartoon character, or a random animal meme breaks the horror tone and is a fix, not a gag. **Also flag gags the editor invented on lines the script did not mark as jokes**, especially in sections the materials sheet marks tragic or apocalyptic.
11. **Roster / section cards:** section intro = punch-in zoom into the creature card; roster grid (8-card) correct — right creatures, right names, right SPELLING, right count, matching this video's roster. Check the roster FONT matches the section titles, that the push-in does not clip labels off the frame edge, and that the outro roster still has its labels. **Check each roster card's ARTWORK against the creature's own section** — a roster card showing a different design of the same creature is a real drift catch.
12. **VO / transcript check:** listen/read for mispronunciations and wrong words (the "FET-ted King" vs "FEH-tid" catch). Flag for owner-side VO regen. Confirm VO matches the approved script (no dropped/altered lines).
13. **CTA:** mid-roll CTA present at the scripted spot (~after creature 3) and outro CTA present; on-register visuals; timing not rushed/clipped; the same subscribe asset used in both. **Verify the mid CTA is actually in the VO, not just missing visuals** — on 2026-08-03 the whole scripted 55-word mid CTA was absent from the recorded voiceover, which is an owner/VO fix, not an editor fix.
14. **Delivery specs:** ≥1920x1080, 30 fps, H.264 MP4, adequate BITRATE, clean export (no black frames, no aspect/letterbox errors, no mid-video resolution drop). Also check the final seconds for asset artifacts (transparency checkerboard edges, upscaled gif dithering).
15. **Retention read:** model a directional retention curve from measured pacing/motion + genre norms (hook % @0:30, mid-video texture, est. % at end) vs the niche bar (~65–75% @30s). Timestamps for any pacing dips that would cost retention. **Weight the back third heavily** — a video can measure perfect on motion and still bleed at 7:00+ if pop density and asset quality taper.
16. **Thumbnail-moment check:** the video actually contains the thumbnail image/beat (per the video's thumbnail spec / assignment sheet).
17. **Third-party / likeness check (added 2026-07-27):** no identifiable real people used as horror illustration, and especially no identifiable minors. Flag any real-world bystander photo pulled in as an asset. **This now covers licensed characters too** (a Minion appeared 2026-08-03) and stock photos of real people used as literal illustrations of a metaphor.

## ASSET-DRIFT sub-checklist (step 6 — the small catches)
- **Wrong creature:** an image of a different monster on a creature's section (or a near-lookalike from another series).
- **Wrong series/universe:** art from a different franchise for a creature (e.g. a Sonic character under a Cartoon Cat title — this actually happened 2026-07-27).
- **Fan-art trap:** an image the materials sheet specifically flags (wrong anatomy — added jaw/teeth, extra limbs, recolored).
- **Orientation error:** an asset flipped or rotated so it contradicts canon (the Upside-Down Face rotated 180° reads as a normal face on an inverted body — the opposite of the creature).
- **Anachronism:** modern object in a period scene (a 2020s car in a 1948 crash photo), wrong-era UI, wrong logo.
- **Style / continuity drift:** canvas color, title font/position/stroke, icon language, palette (any color outside black/white + red accent), or grade that changes between sections without reason; multiple mutually inconsistent designs of the SAME creature within one section (three showed up in one Horned Serpent section, 2026-08-03).
- **Reuse / duplication:** the same asset held too long or reused as if new; a background plate recycled across two different creatures' sections; a placeholder left in.
- **Repaint / upscale drift:** an AI-upscaled or repainted asset whose anatomy, color, or proportions no longer match the canon original (must be QC'd against the source).
- **Literal-metaphor stock photo (added 2026-08-03):** a stock image that illustrates the WORD rather than the canon (a landscaper for "the Gardeners", a county jail for "prisons"). Usually also a real-person likeness problem and a tone break.
- **Text-asset drift:** misspelled creature/series names, missing hyphens, wrong dates, inconsistent numeral formatting, keyword pop that contradicts or misquotes the VO, dangling possessives ("Unknowingly's" with nothing after it).

## SMALL-DETAILS / typo sweep (always run)
Spelling and hyphenation in every text card and keyword pop; date accuracy; creature/series name spelling; title CASE; keyword-to-VO match; canon numbers spoken in VO but never shown on screen (a miss, not an error, but worth flagging); SFX timing (frame-accurate to cue); black/dropped frames; blank title-only frames (a red phrase alone on empty white for 3s, 2026-08-03); abrupt or missing transitions; unfilled quiet gaps >4s; music not ducked; title card missing on a section; roster card typos and clipped labels; CTA text/timing; export artifacts and bitrate; **the last 5 seconds of the video specifically** — the final frame is the highest-leverage frame in the file and it is the one nobody scrubs to.

## Delivery format
- Verdict first (competitor-grade? direction confirmed? or needs another round). One line.
- Per-section notes with **timestamps** (like the Vu QC): what's strong (keep), what's wrong (fix).
- **Corrections as a forwardable DM** to the specific editor: numbered fix list, each with a timestamp, casual direct tone, **no em dashes** (owner preference for editor messages). Put a priority order at the end if the list is long, and close with what to KEEP.
- **DELIVER THE DM PRE-SPLIT INTO 4 CHUNKS (confirmed working 2026-07-27).** The owner sends these on Upwork, which rejects a long single message. A full ~20-item fix list will not send in one go. Always hand it over already split into 4 copy-paste blocks, in plain fenced code blocks, roughly: (1) intro + the first few hard errors, (2) the rest of the hard errors, (3) style/brief violations, (4) polish + priority order + what to keep. Do not paste it as one wall of text and do not wait to be asked to split it.
- Separate owner-side items (VO regen, canon calls only the owner can make).
- **END WITH THE FULL CHECKLIST STATUS** (steps 1–17: green / fix-sent / open). List OPEN items explicitly (unread frame, unverifiable source image, VO pronunciation to confirm).

## PROJECT-WRITE SAFETY (added 2026-08-03 after a real incident)
`project_write` REPLACES a doc in place and there is no version history and no undo. On 2026-08-03 `claude/rotation-log.md` was overwritten with a placeholder string by a misfired write during a QC session and could not be recovered. Before writing to ANY existing project doc: `project_read` it first, edit the full text, and write the complete updated content back. Never send a short or placeholder body to an existing path, not even as a step towards something else. Double-check the `path` argument matches the doc you actually intend to change.
