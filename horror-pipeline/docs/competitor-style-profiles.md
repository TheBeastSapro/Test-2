# Competitor Style Profiles (measured, for a profile-driven renderer)

*Created 2026-08-08. Three reference videos were watched end to end and measured. The point of this doc is that the renderer should NOT hardcode one look. Style is a swappable config. This file holds the measured parameter sets.*

**Do not lock the engine to one profile.** Every number below came from a real video and can be swapped, blended, or A/B tested.

---

## The headline finding, which contradicts our own assumption

We had settled the house style as "M Simplified cinematic-integrated, not white-canvas Ficknime", and treated that as the thing to copy.

Then the biggest video in the niche was measured: **Darkly, "Doctor Nowhere Monsters Explained In 10 Minutes", 2.73M views. It is 85 percent boxed white canvas.** Closer to Ficknime than to M Simplified. It beats M Simplified's own Doctor Nowhere video (186K) by roughly 14x on the same subject.

**Layout is not the lever.** What separates the 2.7M video from the 400 to 600K field is measurable and it is not the frame:

1. **Cold open.** First fact at 0:01. No welcome, no intro, no "in today's video". Competitors spend 10 to 15 seconds on a hook preamble.
2. **Icon density.** 3 to 5 icons per concept where competitors use one static image.
3. **Narration speed.** 160 to 180 wpm against a competitor field of 120 to 140.
4. **Layer cadence over cut cadence.** Visuals update every 1.5 to 2.0 seconds by ADDING a layer, even when the background persists. The cut rate is the same as everyone else at ~2.2s; the change rate is faster.

Keep the cinematic-integrated house look because it is the owner's taste and it differentiates. But do not expect layout alone to move views. Density and pace are where the measured gap is.

## Universal constants (true in all three, treat as invariants)

| Parameter | Value |
|---|---|
| Average shot length, first 60s | **2.2 to 2.3 seconds** |
| Longest hold anywhere | **4.0 seconds**, never exceeded |
| Fully static runtime | **0 percent** |
| Baseline zoom on every image | **1.05x to 1.10x**, continuous |
| Icon entry animation | pop, scale 0 to 110 to 100 percent, ~0.2s |
| Text sync | lands on the **first syllable** of the narrated keyword |
| Keyword caption length | **1 to 4 words** |
| Persistent creature title | top-center, every frame |
| Music | constant low-frequency ambient drone |
| VO ducking | **-12 dB** under narration |
| Section opener | roster grid, then digital punch-in to the creature's cell (~0.5s) |

## How the renderer should consume this

Style belongs in a config file, not in component code. A profile is roughly:

```
{
  "name": "house",
  "extends": "m-simplified",
  "layout": { "fullFramePct": 0.72, "whiteCanvasTrigger": ["number","size-comparison","icon-list"] },
  "title":  { "font": "anton", "case": "upper", "fill": "#FFFFFF", "stroke": "#111111", "pos": "top-center" },
  "palette":{ "bg": "#FFFFFF", "ink": "#111111", "accent": "#D62020" },
  "caption":{ "maxWords": 4, "pos": "frame-dead-space", "anim": "pop", "animMs": 200 },
  "pacing": { "avgShotSec": 2.2, "maxHoldSec": 4.0, "layerEverySec": 1.8 },
  "roster": { "cells": 8, "punchInSec": 0.5 },
  "audio":  { "duckDb": -12, "sfxPerMin": 18 },
  "motion": { "zoomPerShot": [1.05, 1.10], "iconSlidePxPerSec": 500, "shakeOnImpact": true }
}
```

The three profiles above are the seed configs. The house profile extends one of them and overrides. A validator enforces the universal constants regardless of profile: max hold 4.0s, zero static runtime, text present on every frame, captions 4 words or fewer.

**Our house palette (white / black / red #D62020) is a deliberate divergence, not an imitation.** None of the three references use it. M Simplified uses green and yellow, Ficknime uses per-section colours, Darkly uses red only for blood. Red as the single accent comes from `claude/thumbnail-spec.md` and is a branding choice worth keeping for recognisability, but it should live in the profile so it can be tested against a green/yellow variant.

## Open questions worth testing

1. **Cold open.** Do our videos start the first fact at 0:01? The leader does. Worth auditing the published cut.
2. **Narration speed.** Our scripts run about 1,570 words over 8:45 to 9:15, which is roughly 170 to 180 wpm. That is already in the leader's band. Confirm the delivered VO has not slowed it down.
3. **Icons per concept.** We are likely at 1 to 2 where the leader is at 3 to 5. This is the cheapest available improvement and it does not need better art.
4. Green/yellow accent variant against our red, as a thumbnail and in-video A/B.
